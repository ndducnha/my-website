# ducnha.work

Personal website of Nguyễn Đình Đức Nhã: a static one-page bilingual site (EN at `/`, VI at `/vi/`) served by GitHub Pages.

- Edit content in `_build/content/onepage.mjs`, then run `node _build/build.mjs` (Node 18+).
- Generated files: `index.html`, `vi/`, `en/`, `404.html`, `sitemap.xml`, `robots.txt`. Do not edit these by hand.
- Full guide: `_docs/README.md`. Open items for the owner: `_docs/verification-checklist.md`.
